# DISC1 Study Repository

This repository contains data, models, and tracking files for studying the **DISC1** (Disrupted in Schizophrenia 1) gene and associated phenotypic data.

---

## Repository Contents

### Protein Models & Sequences
* `AF-Q9NRI5-F1-model_v6.pdb`: AlphaFold structural model ([View File](https://github.com/hazixity-blip/DISC1-Study/blob/main/AF-Q9NRI5-F1-model_v6.pdb))
* `disc1_alphafold_structure.png`: Visualization of the AlphaFold structure ([View File](https://github.com/hazixity-blip/DISC1-Study/blob/main/disc1_alphafold_structure.png))
* `ENSMUST00000098311.11.fasta`: Mouse transcript FASTA file ([View File](https://github.com/hazixity-blip/DISC1-Study/blob/main/ENSMUST00000098311.11.fasta))
* `ENST00000439617.8.fasta`: Human transcript FASTA file ([View File](https://github.com/hazixity-blip/DISC1-Study/blob/main/ENST00000439617.8.fasta))
* `uniprotkb_2026_08_24.fasta.gz`: UniProtKB sequence archive ([View File](https://github.com/hazixity-blip/DISC1-Study/blob/main/uniprotkb_2026_08_24.fasta.gz))
